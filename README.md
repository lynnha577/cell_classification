# Cell Classification

## Fresh environment setup

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

> Note: `requirements.txt` is pinned to Python 3.10 (`python_version >= 3.10 and < 3.11`), so using a different Python version can skip installs.
